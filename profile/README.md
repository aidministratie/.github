# aidministratie

**Sovereign Agent-as-a-Service Infrastructure for European SMEs**

aidministratie delivers sovereign, multi-tenant AI automation bridges for European small and medium-sized enterprises. We bridge everyday business applications with state-of-the-art AI reasoning models while strictly upholding European data sovereignty, zero public model training, and Human-in-the-Loop oversight.

---

### 🌐 Official Repositories & Connectors

* **[`aidministratie/mcp`](https://github.com/aidministratie/mcp)**: Official Model Context Protocol (MCP) Streamable HTTP/SSE gateway for Claude Desktop, Cursor, Antigravity, and AI Agents.
* **[`aidministratie/copilot`](https://github.com/aidministratie/copilot)**: Declarative Agent and Microsoft Teams application package for Microsoft 365 Copilot.

---

### 🛡️ Sovereign European Architecture

* **100% European Hosting:** Dedicated ISO/IEC 27001 data centers located in the EU (Germany and Finland).
* **Zero Model Training Guarantee:** Customer data, business cards, contracts, and financial metrics are never used to train or fine-tune public foundation models.
* **Envelope KMS Encryption:** All Virtual File System (VFS) assets are protected with AES-256 envelope encryption.
* **Human-in-the-Loop Safeguards:** Administrative mutations and financial actions require explicit human authorization before execution.
